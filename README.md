# Трио

Утилита для Windows 10 и 11. Трио автоматически находит виртуальный выход **Trio**, созданный драйвером VB-CABLE, и передаёт его звук на пять устройств одновременно. Можно использовать от одного до пяти выходов. Громкость каждого регулируется отдельно во время воспроизведения.

## Установка

Скачайте [установочный архив Trio-1.3.0-Windows.zip](../../releases/download/v1.3.0/Trio-1.3.0-Windows.zip) и распакуйте его целиком. В архиве находятся `Trio.exe`, инструкция `INSTALL.txt` и вложенный архив драйвера `VBCABLE_Driver_Pack46.zip`. Пункты **Source code** на странице релиза содержат исходники для сборки.

1. Распакуйте вложенный `VBCABLE_Driver_Pack46.zip`, запустите установщик от имени администратора и перезагрузите ПК. Драйвер добавит выход **CABLE Input (VB-Audio Virtual Cable)**. Если VB-CABLE уже установлен, переходите к следующему шагу.
2. Откройте `Trio.exe` и нажмите **Переименовать**. В свойствах устройства Windows задайте имя **Trio**. Свойства также можно открыть через **Параметры → Система → Звук**. В списках Windows и Zoom имя может отображаться вместе с названием драйвера. [Свойства имён аудиоустройств Windows](https://learn.microsoft.com/windows-hardware/drivers/audio/friendly-names-for-audio-endpoint-devices)
3. Подключите наушники через параметры Bluetooth Windows. Назначьте до пяти устройств в слотах Трио и нажмите **Запустить вывод**.
4. Нажмите **Звук Windows** и в разделе **Вывод** выберите **Trio**. Windows сделает его выходом по умолчанию. Если у отдельного приложения в **Микшере громкости** задан другой выход, выберите **Trio** или **По умолчанию**. [Настройка вывода Windows](https://support.microsoft.com/en-us/windows/hardware/audio/fix-audio-issues-when-no-sound-plays-from-speakers-or-headphones-in-windows)
5. В Zoom откройте **Настройки → Звук → Динамик**, выберите **Trio** и нажмите **Проверить динамик**. В Трио загорится индикатор входного сигнала. [Инструкция Zoom](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0062765)

Для стереозвука через Bluetooth Classic в Zoom можно выбрать встроенный или USB-микрофон. Микрофон Bluetooth-наушников может переключить гарнитуру в режим связи с монофоническим звуком. [Документация Windows](https://learn.microsoft.com/windows-hardware/drivers/bluetooth/bluetooth-classic-audio)

## Как работает вывод

- Пока виртуальный выход назначен в Windows, оставляйте Трио запущенным для воспроизведения. Чтобы вернуться к обычному выводу, выберите динамики или наушники в настройках звука Windows.
- Трио отправляет один и тот же поток на выбранные выходы. Задержка в отдельных парах может отличаться из-за Bluetooth-кодеков и буферов самих наушников.
- Для пяти пар одновременно Windows и Bluetooth-адаптер должны поддерживать активное воспроизведение на всех пяти устройствах.
- Если устройство временно отключилось, Трио пытается подключить его снова. Чтобы назначить другой выход, остановите вывод, выберите устройство и снова запустите вывод.

## Драйвер VB-CABLE

VB-CABLE разработан VB-Audio Software и распространяется как donationware. В комплект входит исходный архив производителя. Вы можете поддержать разработчиков пожертвованием или покупкой лицензии. [VB-CABLE](https://www.vb-cable.com/) · [Условия распространения](https://vb-audio.com/Services/licensing.htm)

## Сборка

Запустите `.\build.ps1` в PowerShell из папки с исходниками. Скрипт использует компилятор .NET Framework и создаёт `Trio.exe` в той же папке.

Для сборки установочного архива положите рядом оригинальный `VBCABLE_Driver_Pack46.zip` с [сайта VB-Audio](https://vb-audio.com/Cable/) и запустите `.\package.ps1`.
